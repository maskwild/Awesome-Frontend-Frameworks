# ⭐ 主流前端框架

| 框架 | GitHub | 类型 | 特点 | 适合 |
|---|---|---|---|---|
| [React](https://react.dev) | https://github.com/facebook/react | UI 库 | 生态最丰富、组件化、社区庞大 | 大型应用、SaaS、企业项目 |
| [Vue](https://vuejs.org) | https://github.com/vuejs/core | 渐进式框架 | 简单易学、中文生态完善、开发效率高 | 中后台、企业网站、快速开发 |
| [Angular](https://angular.dev) | https://github.com/angular/angular | 企业级框架 | TypeScript、完整工程体系、强约束 | 大型企业应用 |
| [Svelte](https://svelte.dev) | https://github.com/sveltejs/svelte | 编译型框架 | 无 Virtual DOM、性能优秀、代码简洁 | 高性能 Web 应用 |
| [SolidJS](https://www.solidjs.com) | https://github.com/solidjs/solid | 响应式框架 | 细粒度更新、高性能、接近原生 | 性能敏感项目 |
| [Preact](https://preactjs.com) | https://github.com/preactjs/preact | 轻量框架 | React API、体积小、速度快 | 小型应用、移动端 Web |
