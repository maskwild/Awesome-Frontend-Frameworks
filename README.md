# ⚛️ React 生态

## React

官网：
https://react.dev

GitHub：
https://github.com/facebook/react


特点：

- 组件化开发
- 丰富生态
- 大量企业应用
- 社区资源丰富


适合：

- 大型 Web 应用
- SaaS 平台
- 企业后台


---

## Next.js

官网：

https://nextjs.org


GitHub：

https://github.com/vercel/next.js


简介：

React 全栈框架，支持：

- SSR 服务端渲染
- SSG 静态生成
- API Routes
- 全栈开发


适合：

- 企业官网
- 电商
- SEO 网站


---

## Remix

官网：

https://remix.run


GitHub：

https://github.com/remix-run/remix


简介：

基于 React 的现代 Web 框架。

特点：

- Web 标准优先
- 数据加载优化
- 服务端渲染

# 🆕 新兴前端框架


## Svelte

官网：

https://svelte.dev


GitHub：

https://github.com/sveltejs/svelte


简介：

## SolidJS

官网：

https://www.solidjs.com


GitHub：

https://github.com/solidjs/solid


简介：

- 高性能更新
- 低运行成本
